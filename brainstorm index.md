## Quick Wins vs Deep Work

**Quick wins (do first)**
- Ops Agent: basic system health monitor + ntfy alerts
- Health Agent: training log parser
- Knowledge Agent: Obsidian semantic search
- Telegram unified inbox
- Model routing rules in config

**Deep work (requires more infra)**
- Long-term memory with vector DB
- Meta-orchestrator / task router
- Cross-agent shared context engine
- Full cyber agent with live tooling
